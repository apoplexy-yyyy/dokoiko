# どこいこ（神奈川県プロトタイプ）

「今日、子供とどこに行こう？」——行き先が決まっていない休日に、**近所にあるのに知らなかった場所**を偶然発見するための静的Webアプリです。
検索条件を入れて探すのではなく、地図を動かすと、表示している範囲の**子供向けイベント**（今日・今週末・2週間）と、子供と行ける場所6か所（重み付きランダム）を提示します。

## しくみ

```
GitHub Actions（毎週土曜）
  ①  OpenStreetMap (Overpass) … 公園・遊び場・博物館・水辺・児童館/こども文化センター/子育てひろば・道の駅など＋遊具/トイレの位置・公園の広さ
  ②' Wikidata 照合            … wikidataタグのないスポットを、県内の項目と名前＋位置で結び付け
  ②  Wikidata                 … 説明文・画像・公式サイト・知名度(sitelink数)
  ③  Wikipedia(ja)            … 記事冒頭の要約
  ④  Wikimedia Commons        … 画像サムネイル・作者・ライセンス
  ④' Commons 位置検索         … 写真のない施設の近くで撮られ、ファイル名に施設名を含む写真
  ⑤  自治体RSS 等              … 新着情報（スポット名/市町村で照合）
        ↓ build-data（スコアリング・重複除去・0.05°タイル分割・広域用おすすめ抽出）
  public/data/kanagawa/{meta.json, news.json, highlights.json, tiles/*.json}
        ↓ vite build
GitHub Pages（広域表示は highlights.json、拡大時は表示範囲のタイルだけを読む）

GitHub Actions（毎日）
  ⑥  子供向けイベント          … 川崎市イベントAPI（会場の座標・対象年齢つき）、横浜市イベント情報（子育て、区単位）
        ↓ 会場名で施設と照合
  public/data/kanagawa/events.json（45日先まで）
```

### イベント（`scripts/collect-events.ts`）

- **川崎市**：[かわさきイベントアプリ Web API](https://eventapp.city.kawasaki.jp/data/api/v1/reference.html)（CC BY 2.1 JP）。対象が乳児・幼児・小学生のもの、または全世代向けでジャンルが「遊び・子ども子育て・小学生向け」のもの
- **横浜市**：市サイトのイベント検索データのうちジャンル「子育て」。会場の座標が無いため区の中心に置き、タイトル・日付・リンクだけを使う
- 講習会・説明会・長期の募集など、子連れで出かける理由になりにくいものは除外
- 県内のほかの市町村は、使えるイベントデータが見つかっていない（県のイベント一覧はフィードなし、観光協会のサイトは転載不可）

### 発見ロジック（`src/discover/pick.ts`）

重み = 子供向け度 × 行く価値（公園は広さ）× 意外性（有名すぎない）× 情報の充実度 × 未発見ボーナス × **この範囲での特徴度（TF-IDF）**

- **TF-IDF**：各スポットに特徴語（タグ由来の「滝」「ミュージアム」、名前由来の「梅」「やぐら→洞窟」「じゃぶじゃぶ→水遊び」など。`config/terms.json`）を付ける。
  語の重み = (1 + ln 表示範囲内の出現数) × IDF（ln 全スポット数 / その語を持つスポット数）。
  どこにでもある「公園」は低く、県内では珍しいがこの範囲にある語は高くなる。重みの大きい語は「この範囲の特徴」として画面に出す
- 地図の表示範囲が変わるたびに選び直す（ボタン操作なし）
- 画面は全面の地図。上部にタイトル・概要・操作、地図の右上に凡例（種類ごとの表示 on/off、すべてオン／すべてオフ）
- 地図には表示範囲の場所を順位の高い順に置き、ほかのピンと重ならないものはすべて出す。**得点（重み）が高いほどアイコンが大きく濃い**。上位6か所（おすすめ）は必ず出し、縁取りで目立たせる。名前ラベルも重ならないものだけ表示する
- アイコンを押すと吹き出しに詳しい情報（写真・説明・イベント・Google検索・行き方）を出す
- 乱数は「日付＋スポットID」から決まるので、同じ日に地図を少し動かしても候補は入れ替わらず、日が変わると顔ぶれが変わる
- **公園は表示しない**（データの7割を占め、候補が公園ばかりになるため。データには残し、イベント会場との照合には使う）。遊び場のうち「〇〇公園」「児童遊園」など実質は街区公園のもの、遊具単体や園庭も出さない
- ジャンルを5グループ（公園・遊び場／自然・水辺・眺め／学び／児童館・子育てひろば／生きもの・あそび・直売）に分け、遊び場1.5割・あそび等2.5割・ほかは2割ずつを目安に枠を配る
- 児童館・こども文化センター・子育て支援拠点・こどもログハウス・プレイパークは、OSMでタグがまちまち（community_centre・social_facility・building=public など）なので、名前で拾う
- 以前に表示した場所はブラウザに記録し、次に開いたときは出にくくする
- 「雨の日」は屋内施設だけから選ぶ

## 開発

```powershell
npm install
npm run dev          # http://localhost:5173
npm test             # 単体テスト
npm run build        # dist/ に出力
```

### データ収集

```powershell
npm run collect                  # すべて（OSMは数十分かかることがあります）
npm run collect -- --skip-osm    # OSM取得を省略して ②〜⑤＋統合だけ
npm run build:data               # .work/ の中間データから再出力だけ
npm run collect:events           # イベントだけ取り直す（数十秒）
```

- HTTP結果は `.cache/` にキャッシュされます（Overpass 20時間、Wikimedia 6日、Commons位置検索 13日、RSS・イベント 6時間）
- OSM取得に失敗した場合は公開データを更新しません。②〜⑤の失敗はスキップして続行します

### 設定

| ファイル | 内容 |
| --- | --- |
| `config/region.json` | 対象地域（ISO 3166-2コード、範囲、タイルサイズ） |
| `config/categories.json` | 収集するOSMタグとカテゴリ・子供向け基礎点・屋内フラグ |
| `config/terms.json` | TF-IDF に使う特徴語（タグ→語、名前に含まれる語） |
| `config/feeds.json` | 新着情報のRSS/Atom、子供向けキーワード、Google News設定 |

## GitHub Pages で公開

1. GitHub にリポジトリを作成して push（`main` ブランチ）
2. Settings → Pages → Source を **GitHub Actions** に設定
3. Actions の「データ収集（週次）」を手動実行すると、データ更新後に自動でデプロイされます

## データの出典とライセンス

- 地図・施設データ：© OpenStreetMap contributors（ODbL）
- Wikidata（CC0）／Wikipedia（CC BY-SA 4.0、要約に記事リンクを併記）
- 画像：Wikimedia Commons（各ファイルの作者・ライセンスをカード上に表示）
- 新着情報：各自治体サイト（タイトル・日付・リンクのみ保存し、本文は転載しない）
- イベント：川崎市 かわさきイベントアプリ（CC BY 2.1 JP）、横浜市 イベント情報（タイトル・日付・リンクのみ）

> **Google News RSS について**：フィードの利用規約が「個人・非商用のフィードリーダー用途」に限定されているため、`config/feeds.json` で既定は無効（`googleNews.enabled: false`）にしています。公開サイトや事業化で使う場合は、利用条件を確認してください。
